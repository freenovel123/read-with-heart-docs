# 🎨 段评样式

> **让段评按钮融入你的阅读主题！**
>
> 段评按钮（`<comment>` 标签渲染的评论按钮）样式由 App 阅读主题和段评图标配置决定，书源正文中不需要额外写 CSS。本文介绍 App 内自定义段评图标的完整能力。

---

## 1. 自定义段评图标（SVG 模板）

App 内"段评图标"支持新建和导入自定义 SVG 模板。模板中可使用以下变量：

**数量变量**

| 变量 | 说明 |
|------|------|
| `{{count}}` | 评论数量 |

**阅读主题颜色变量**（2026-08 新增）

| 变量 | 说明 |
|------|------|
| `{{readBG}}` | 正文背景色 |
| `{{readFont}}` | 正文字色 |
| `{{menuBG}}` | 菜单背景色 |
| `{{menuFont}}` | 菜单文字色 |

主题颜色变量可以用在以下位置，图标会随当前阅读主题（含自定义阅读背景）实时变色：

- `fill` / `stroke` 属性
- 内联 `style`（如 `style="fill:{{readFont}}"`）
- 渐变颜色（`<linearGradient>` / `<radialGradient>` 的 `stop-color`）
- `<text>` 文字颜色

示例：底色跟随正文背景、描边和数字跟随正文字色的圆形段评图标：

```html
<svg viewBox="0 0 24 24">
  <circle cx="12" cy="12" r="11" fill="{{readBG}}" stroke="{{readFont}}" stroke-width="1"/>
  <text x="12" y="16" font-size="10" text-anchor="middle" fill="{{readFont}}">{{count}}</text>
</svg>
```

!!! note "兼容规则"
    - 使用固定颜色（如 `#FF3B30`）的属性不随主题变化，只有显式写变量的属性才会变色
    - 旧版自定义图标未指定颜色时按**正文字色**渲染；进入 App 编辑页保存后会自动迁移为 `{{readFont}}`
    - 切换阅读主题或背景后，图标会按四色快照重新渲染，不会残留旧主题颜色

## 2. SVG 编辑器快捷输入

在 App 段评图标的 SVG 代码编辑器中输入 `{{` 会弹出快捷菜单，提供 `{{count}}` 和四种主题颜色变量，附带中文说明，无需手写完整变量名。

## 3. 解析属性编辑

段评图标编辑页提供"解析属性"入口，可编辑 SVG 自动解析出的属性，按分类（全部 / 颜色 / 字号 / 对齐 / 坐标）筛选：

- **单项编辑**：图形填充 / 描边颜色、字体颜色、文字大小、文字 X / Y 坐标、水平 / 垂直对齐
- **颜色来源**：正文背景色 / 正文字色 / 菜单背景色 / 菜单文字色 / 自定义颜色
- **批量修改**（颜色分类下）：按全部颜色 / 全部填充 / 全部描边 / 字体颜色范围，批量应用主题变量或自定义颜色
- Sheet 内修改**即时预览**，最终仍由编辑页"保存"写入图标配置
