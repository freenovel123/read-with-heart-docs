# 🖍️ 高亮样式

> **让关键词在正文中脱颖而出！**
>
> 高亮规则（阅读菜单 → 高亮规则）按正则表达式匹配正文文字，并对命中的内容应用自定义前景、背景、装饰、阴影与描边样式。适合突出主角名、功法名、地名等关键词，也可用于正文美化。

---

## 1. 功能入口

阅读页菜单 → **高亮规则**。列表页可新建、编辑、删除规则，支持 iCloud / 文件导入。

首次进入时会自动导入 App 内置的常规高亮规则；之后也可手动重新导入，同名全局规则会被覆盖，**用户自建规则不会被删除**。

## 2. 规则匹配

每条规则分三个编辑页签：**规则匹配**、**样式设置**、**背景设置**。

规则匹配页签配置：

| 配置项 | 必填 | 说明 |
|--------|------|------|
| 标题 | 否 | 规则名称，便于管理 |
| 分组 | 否 | 规则分组 |
| 匹配内容 | **是** | 正则表达式 |
| 作用域 | 否 | **全局**（所有书籍生效）或 **本书**（仅当前书籍） |
| 状态 | 否 | 启用 / 停用该规则 |

!!! note "匹配内容写法"
    - 每行一条匹配规则，可一次匹配多个关键词
    - 支持净化规则 `pattern=replacement` 写法，但**只取 pattern** 部分参与高亮
    - 示例：`主角|萧炎|炎帝` 一行即可同时高亮三个词

## 3. 常用正则示例

### 标点符号类

| 场景 | 正则 | 说明 |
|------|------|------|
| 中文弯引号 | `“[^”]*”\|‘[^’]*’` | 高亮双引号/单引号内的完整内容（含引号） |
| 直角引号 | `「[^」]*」\|『[^』]*』` | 日系轻小说常用引号内完整内容 |
| 书名号 | `《[^》]*》` | 高亮《书名》《功法》等完整内容 |
| 省略号 | `…{2}` | 中文省略号（……），两个字面省略号字符 |
| 破折号 | `—{2}` | 中文破折号（——），两个 em dash |
| 英文引号 | `"[^"]*"\|'[^']*'` | 英文双/单引号内完整内容 |
| 仅引号本身 | `[“”‘’「」『』]` | 只高亮引号字符，不包含内容，适合强调对话边界 |

### 内容类

| 场景 | 正则 | 说明 |
|------|------|------|
| 感叹 / 疑问句 | `[^。！？\n]*[！？]` | 高亮以 ！或 ？ 结尾的整句（不含句号句） |
| 数字 | `\d+\.?\d*` | 高亮数字（章节号、修为等级等） |
| 多关键词 | `主角\|萧炎\|炎帝` | 竖线分隔，一行同时匹配多个词 |

### 搭配建议

- **对话高亮**：引号内完整内容（`“[^”]*”`）+ 浅色背景 + 圆角，视觉上把对话“框”出来
- **强调边界**：仅引号本身（`[“”]`）+ 前景色，轻量不干扰阅读
- **书名/功法**：书名号内容 + 字重加粗 + 字号轻微放大，突显专有名词
- 多条规则同时命中同一段文字时，可叠加背景与前景效果

## 4. 样式设置

前景样式决定命中文字本身的呈现，浅色 / 深色阅读主题可分别配置：

- **前景模式**：设置命中文字使用自定义前景
- **前景颜色**：浅色主题一套、深色主题一套
- **字体**：自定义命中文字的字体
- **字重**：加粗等字重调整
- **字号缩放**：相对正文字号放大 / 缩小

## 5. 背景设置

背景设置决定命中内容的底衬效果，同样支持浅色 / 深色双主题：

**纯色背景**

- 背景颜色（浅色 / 深色各一套）
- 背景圆角

**背景图片**

- 选择背景图片，作为命中内容的底衬
- **延展区域**：按水平 / 垂直方向编辑图片可延展（切片）区域，适配不同长度文本
- 背景透明度
- **内容缩进**：文字相对背景图边缘的留白
- 背景图实时预览

**装饰线**

- 装饰类型与绘制模式
- 装饰颜色（浅色 / 深色）与偏移

**阴影与描边**

- 阴影：开关、颜色、模糊 / 偏移参数
- 描边：开关、颜色、宽度

## 6. 实时预览

编辑页底部提供预览区：

- **预览模式**：浅色 / 深色切换，分别核对两套主题下的效果
- **预览文本**：自定义用于预览的文字内容
- 预览随配置实时刷新

## 7. 与净化规则的区别

| 能力 | 净化规则 | 高亮规则 |
|------|----------|----------|
| 作用 | **替换 / 删除**正文内容 | **只装饰**正文内容，不改动文字 |
| 匹配 | 正则 | 正则（每行一条，兼容净化写法） |
| 作用域 | 全局 / 书籍 | 全局 / 书籍 |

两者可同时命中同一段文字：先净化后高亮。
